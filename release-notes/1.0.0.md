headline: Bay 1.0: a beautiful, fast browser for Mac
---

The first release of Bay. It brings everything you loved about Arc, built on Chrome's own engine, so pages
render, sign in and behave as they do in Chrome.

- **The sidebar.** Favorites on top, pinned tabs under them, today's tabs below.
- **Spaces**, each with its own icon, theme and profile, so sign-ins stay apart. Swipe between them.
- **Folders** group tabs under a name. Hover a folder, Gmail or GitHub tab for a preview.
- **Old tabs put away** after a time you choose for each space. They stay one search away.
- **Peek** opens a link over the page. **Split View** puts two tabs side by side.
- **Little Bay**: links from Slack, Mail or Discord open in a small window.
- **Command bar** (⌘L) for addresses, searches, open tabs and the ones put away. ⌃Tab switches between recent tabs.
- **Chrome extensions** from the Chrome Web Store, with uBlock Origin Lite built in.
- **Import** from Arc (spaces, pinned tabs, folders, favorites), Chrome, Safari, Firefox and Dia: bookmarks, history
  and passwords too.
- **Encrypted sync** through a folder you choose, like one in iCloud Drive, with a key only you hold.
