What Arc has that Bay doesn't

Summary

Bay already matches most of Arc: spaces with themes and profiles, favorites, pinned tabs and nested folders, auto cleanup, Peek, Split View, Little Bay, link rules (Arc's Air Traffic Control), the command bar with actions and site search, Capture, Easels, the Library, previews, live folders and calendars, and the media players. The review found 22 gaps and 7 things to re-test. The ten small ones (Phase 1), the three keyboard, undo and Finder ones (Phase 2) and Boosts (Phase 3) have shipped and are listed under Already in Bay; 7 gaps remain.

The gaps left are sharing and Arc Max: shared folders, Share Quote, Easel links, and the "tidy" AI features. Each needs a decision before work starts.

Phase 1 landed before Arc's sunset reminders start on 23 November. The phases left don't depend on Arc's dates.

Arc's sunset

The Browser Company announced on 22 October 2026 that Arc will be sunset. New accounts stopped that day. On 23 November Arc starts showing sunset reminders. On 22 December Arc for macOS and Windows stops working, sign-in ends and all Arc services are turned off. The official path is to move to Dia.

That gives Bay 58 days during which every Arc user is choosing a browser. Bay's Arc importer reads StorableSidebar.json straight from disk (packages/import/ios/Core/Discovery.swift), so it should keep working after Arc stops opening, as long as the files stay on disk. Re-test it against a profile from Arc's final build (see Re-test).

Arc removed some features itself before the end. They are not gaps:

  • Ask on Page, removed from Arc Max on 28 August 2025.
  • Arc Notes, phased out in April 2024. Bay's command bar already opens new notes in Notion, Confluence, Google Docs and Word.
  • Reader Mode, turned off on 6 June 2024.
  • GitHub previews, replaced by GitHub Live Folders in May 2024. Bay has both.
  • The Recent Tab indicator (removed February 2024) and the iCloud sidebar sync (replaced by Arc Sync, June 2024).

Phase 4

Sharing

Decision first

Arc shared things through its own servers, which are being turned off. Bay has none. Decide how to host before starting items 17 and 18.

16 · Share Quote M

Bay's selection popover already copies a link to the highlighted text. Add "Share Quote": render the quote, page title and site in the space's colours as an image, put the image and the text-fragment link on the pasteboard, and offer the share sheet. Done in the shell, needing no server.

Where
site/SelectionPopover.tsx, site/selection.ts, shell image rendering
  • Pasting into Messages gives the card image; pasting into a text field gives the link, which opens scrolled to the quote.

17 · Share a folder, split or selection as a link M

Recommended without a server: compress the titles and links into the fragment of a link on the Bay website (bay.krishkalaria.in/share#…). The fragment never reaches the server. The page lists the links in any browser and has "Add to Bay", which opens a bay:// link that imports it as a folder.

Where
sidebar/menus.ts, apps/web share page, URL scheme handler in AppDelegate.swift
  • A 30-tab folder shared to Chrome lists every link; "Add to Bay" recreates it with nested folders.

18 · Share an Easel as a web page L

Easels hold images, so they don't fit in a link. This needs storage somewhere: a hosted bucket with unlisted links, or the user's own iCloud Drive public link. Until decided, the HTML export stays the way to share.

Where
library/export.ts, plus whatever host is chosen

Exit criteria

  • Share Quote shipped; collection links shipped if the fragment approach is chosen; Easel hosting either decided or recorded as out of scope.
Phase 5

Arc Max, on device

Research gate

Arc Max's lasting features were the small "tidy" ones. Build them on Apple's on-device model so nothing leaves the Mac, if the research spike shows the quality is good enough.

Research spike first (S): run 200 real tab titles, 100 download names and 20 sets of today's tabs through the on-device model. Go ahead only if the results are better than the originals most of the time and fast enough to feel instant.

19 · Tidy Tab Titles M

When a tab is pinned, suggest a short name ("Inbox – Gmail" becomes "Gmail"). The original stays one click away as Reset Name, which Bay already has.

20 · Tidy Downloads S

Offer a readable name for downloads like IMG_20261024_8812.pdf, based on the page and file. Applied only when accepted, never to files the user named.

21 · Tidy Tabs M

A button over today's tabs groups them by topic into Bay's tab groups, with ⌘Z to undo (needs item 12). Pinned tabs and existing groups are left alone.

22 · 5-Second Previews M

Shift-hover a link to load it in the background and show a short summary card with Open, Peek and Copy. Uses the Peek loader and the on-device model.

Where
New shell module for Foundation Models; sidebar/, DownloadsPanel.tsx, layout/usePeek.ts
Availability
macOS 26 with Apple Intelligence on. Hidden elsewhere.

Exit criteria

  • Spike passed and recorded; each feature off by default, reversible, and invisible on Macs without the model.

Risks

Boost injection (reviewed)

Arc's September 2024 hole was its Boost server's access rules; Bay has no Boost server. JavaScript never leaves the Mac: it isn't in a Boost's synced record, imported scripts arrive off, and a synced site change clears this Mac's script consent. It runs off by default, after a warning, in its own isolated world with the page's origin and CSP (no extra privileges), and not in private windows unless allowed. Selectors and font names that could end a CSS rule early are refused, including ones a page sends back while picking. Like extensions' content scripts, every renderer of a regular profile holds the Boost list, so a compromised renderer could read it.

On-device model reach

Bay supports macOS 14, but the model needs macOS 26 with Apple Intelligence. Phase 5 reaches only part of the users; a cloud model would break Bay's privacy stance.

Links in fragments

Very large folders make long links, and anyone holding the link can read it. Cap the size and say so in the share sheet.

Assumptions in this plan

  • Arc's feature list comes from its macOS release notes (2021 to October 2026) and coverage of Arc Max. The 2025–2026 notes contain only fixes.
  • "Missing" is based on searching the code; the app was not run for this review.
  • Sizes are rough and assume one person familiar with the codebase.

Not in this plan

  • Features Arc removed: Ask on Page, Arc Notes, Reader Mode, People Cards, the Recent Tab indicator.
  • Arc account extras: membership cards, Gift Arc and referral-locked icons.
  • Phone apps and sync to iPhone: Arc Search is a separate product. Bay syncs between Macs and accepts Handoff.
  • Windows and Linux: covered by their own ports.
  • Previews for Notion, Figma, Linear, Outlook and Confluence, and search inside folder previews: deferred until asked for.
  • Earlier plan items that Arc never had: clipboard history, one-time codes, "Allow ads here", text from images and push notifications with the tab closed. They stay open but aren't Arc gaps.
