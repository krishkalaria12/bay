Summary

Bay already covers most of what a sidebar browser needs. The review found 17 gaps and 14 areas to re-test. The gaps fall into three kinds: small missing pieces around tabs, media and downloads; two organising features that Arc users rely on (folders inside folders, and rules for links from other apps); and a few larger builds (site tweaks, text in images, notifications with the tab closed) that need a decision before work starts.

The order below fixes first, then ships the small wins, then the features that change how people organise their tabs, and leaves the uncertain work for last behind a research gate.

Phases 0 and 1 are done. Completed on 14 October 2026. The shutdown fix, browser regressions and all six quick wins are implemented. Idle tabs now use a two-hour threshold, and Settings › Tabs has a seeded keep-awake list. Validation and recurring release checks are recorded directly in each phase below. Emoji, unit and currency answers in phase 3 are also done, with an enabled-by-default Calculator toggle and larger answer rows.

Fixes

Browsers built on the same parts commonly break in these places. None is known to be broken in Bay. Each is a check: run it, and fix what fails. They make up Phase 0.

# Area How to check
1 Shortcuts on other keyboard layouts On AZERTY, ⌘Z undoes and doesn't close a tab. On German, ⌘[ and ⌘] go back and forward. On Dvorak, shortcuts follow the key's letter.
2 Extension popups that close themselves Bitwarden's popup goes away after Fill, as in Chrome (window.close() from a popup).
3 Password managers right after launch 1Password, Bitwarden and NordPass buttons work on the first click after launch, and after the app has been idle.
4 Passkey prompts from extensions Bitwarden's passkey prompt opens once, closes after a pick, and GitHub's "Continue with passkey" finishes, also on a page left open a while.
5 Extension pages at every launch No welcome or changelog page opens again on relaunch. Removing an extension also removes its data.
6 A helper app quitting Quitting a password manager's desktop helper while its extension is connected doesn't take Bay down.
7 Sign-ins through quit, update and crash A site that keeps you signed in with a session cookie (YouTube's chosen account, for one) is still signed in after ⌘Q, an update and a Force Quit.
8 Leaving a call ⌘W on a Meet tab, or ⌘Q during a call, leaves the call for the others at once.
9 Google's service icons Drive, Calendar, Gmail and Maps show their own icons in the sidebar, not Google's G.
10 Horizontal scroll vs. swipe Scrolling a carousel or a wide table sideways doesn't go back or forward.
11 Keys on a page Arrow keys, Home and End on a page (or a video that seeks with them) don't play the error sound.
12 Waking a sleeping tab A tab that slept comes back scrolled to where it was.
13 Icons behind a bot check Sites that check for bots first (Cloudflare's page, for one) end up with their own icon, not a letter.
14 Dragging a tab out A tab dragged past the window's edge opens in a new window without reloading, including from a window that fills its screen.

Phase 2

Organising

The two features that change how people arrange their tabs and links.

Folders inside folders L Done

Implemented 15 October 2026. Native Debug fixtures cover nesting, empty-folder ordering, drag and drop, ⌘Z, page text Undo and restart. Import and sync tests cover tree order, migration and older clients' flat records. See the nested folders screenshot. Two physical Macs with different released builds have not been exercised.

Before
PinnedFolder in store/types.ts has no parent, so folders are one level deep. The Arc importer (packages/import/ios/Core/ArcSidebar.swift, flatTabs) flattens Arc's subfolders into one folder.
Implemented
Add a parent to folders, capped at five levels. Render them recursively in FolderBlock.tsx. Let drag and drop in sidebar/dnd.tsx drop into and out of a nested folder. Show "Move to Folder" as a tree. Keep subfolders in the Arc import. Migrate stored state and the sync schema, so that a device on an older version still shows the tabs, flattened.
Compatibility
Older devices read the tabs as flat pinned groups; updated devices retain the folder tree.
  • An Arc import with subfolders arrives with the same structure.
  • Dragging a tab or a folder between levels works, and ⌘Z undoes it.
  • Sync round-trips nested folders between two Macs. An older build still sees every tab.
  • Existing installs migrate with no change to what they show.

Rules for links from other apps M Done

Implemented 24 October 2026 as Arc-style link routing (5f2ff798). Unit tests cover matching, source apps, ordering, deleted spaces and sync; test:links drives the native app with links from other apps and Peek's Open as Tab.

Before
Settings › Links had one choice for links from Slack, Discord or Mail: Little Bay, or a new tab (openLinksInLittleBay).
Implemented
lib/externalLinkRules.ts matches each incoming link against an ordered list of rules. As in Arc, new rules match a URL that contains or equals some text; rules saved with a * host or path pattern keep working. A rule can be limited to the sending app's bundle ID, which the macOS app delegate reads from the Apple Event. It opens the link in a chosen space, the most recent space, Little Bay or a new window. The first match wins; anything unmatched goes to the default in Settings › Links, which replaces the old toggle. Rules are added, edited and reordered in settings/panes/LinkRules.tsx and synced as one ordered list (sync/linkRules.ts), with spaces mapped by sync profile.
Planned
An ordered list of rules. Each has an address pattern (a host or path with *, such as github.com/acme/*) and, optionally, the app the link came from. Each rule opens matching links in a chosen space, in Little Bay or in a new window. The first match wins, and anything unmatched follows today's choice. Rules are added, edited and reordered in Settings › Links, and synced.
  • With a rule for linear.app/* going to Work, a Linear link clicked in Slack opens in Work, whichever space is in front.
  • A link that matches no rule behaves as it does today.

Exit criteria

  • Both features are shipped, the migration has been tested on a copy of a real profile, and sync is tested across two Macs.
Phase 3

Command bar & autofill

Make the command bar answer more, without leaving it, and fill one-time codes.

Clipboard history M

Today
None.
Build
Opt-in in Settings › Privacy. The shell watches the pasteboard's change count and keeps the most recent text and links on this Mac only. It skips anything marked concealed or transient (password managers mark theirs) and anything copied in a private window. Type "clipboard" in the command bar, or use a shortcut, to list it. Return pastes the item, and an item can be deleted.
  • A password copied from 1Password never shows. Clearing history empties it, and it never syncs.

Emoji, units and currency M Done

Implemented 16 October 2026 in bac4b54a. Core tests and native fixtures cover top-row answers, Return to copy, unit conversions, live currency rates and the Calculator toggle. The larger answer rows were checked in light and dark mode, in the palette and narrow dropdown, with keyboard scrolling through mixed-height results.

Before
packages/core/src/calculator.ts does arithmetic and functions. emojiData.ts already feeds the icon picker.
Implemented
suggest.ts puts emoji by name ("emoji heart"), local unit conversions ("5 km in mi", "350 f to c") and currency conversions ("100 usd in inr") first. Return copies the answer. SuperCalculator's unit and currency source files are vendored with their MIT license. Calculator and currency rows show a larger answer beneath the expression, a copy icon and Return hint; currency rows also show the rate source and date.
Setting
Settings › Search › Command bar › Calculator defaults to on. Turning it off hides arithmetic, unit and currency answers and prevents new currency lookups. The choice persists and syncs. Emoji search remains available.
Rates
Frankfurter, with ExchangeRate-API and Fawaz Ahmed as fallbacks. Valid dated rates are cached in memory for one hour, and concurrent requests for the same pair share a lookup. Failed requests never substitute hardcoded or expired rates. Arithmetic, units and emoji work offline.
History
The history page uses Legend List in 6746b4ea. A native fixture with 5,000 entries verified virtualization, selection and removal.
  • Each kind shows as the top row with its answer, and Return copies it.
  • The Calculator toggle defaults to on, and an explicit off choice survives persistence and sync.
  • Light and dark layouts, narrow rows and keyboard scrolling were checked in the native app.

One-time codes L

Today
Autofill covers passwords, cards and addresses (site/Autofill.tsx, engine nn_autofill.cc). It doesn't cover codes.
Build
When a field asks for a code (autocomplete="one-time-code", or a field the heuristics recognise), offer the newest code from the last few minutes, and Return puts it in. There are two sources. Messages needs Full Disk Access to read chat.db, so it's asked for only when switched on. Gmail can reuse the Google connection the calendar preview already has (live/googleAuth.ts), if its scopes allow. Skip numbers from security notices, and prefer the newest code.
  • A code texted or mailed to you is offered under the code box within seconds, and only on the site that asked.

"Allow ads here" when a page breaks M

Today
uBlock Origin is built in. Nothing notices when blocking breaks a page.
Build
If a page where the blocker acted is reloaded three times in twenty seconds, offer "Allow Ads Here" in the corner. It adds the site to the blocker's allow list, and Site Controls can take it back.
  • Three quick reloads offer the prompt once. Accepting reloads the page unblocked, and Site Controls shows the exception.

Exit criteria

  • The four items are shipped. Clipboard history and codes are opt-in, and both are covered in the privacy page's copy.

Decisions needed

  1. The idle sleep timer, decided. Two hours for active and inactive spaces, with a configurable keep-awake host list. Under critical memory pressure, eligible keep-awake sites sleep last.
  2. Where link rules can send links. A space, Little Bay and a new window are proposed. Is a specific profile or window also needed?
  3. How older synced devices see nested folders, decided. Flattened pinned groups keep every tab visible; updated devices retain the tree.
  4. The currency rates source, decided. Frankfurter with ExchangeRate-API and Fawaz Ahmed fallbacks. Currency needs a network connection; arithmetic, units and emoji stay offline. The Calculator toggle defaults to on.
  5. The scope of site tweaks. CSS and Zap only, or JS as well.
  6. Whether to read Messages for codes, given the Full Disk Access prompt.
