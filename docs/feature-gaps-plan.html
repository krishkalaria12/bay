What Bay is missing, and what to build next

A gap review of Bay's code against what people expect from a sidebar browser on the Mac. It lists what Bay already covers, the gaps the code has no answer for, the areas to re-test and fix, and the build order in phases.

Summary

Bay already covers most of what a sidebar browser needs. The review found 17 gaps and 14 areas to re-test. The gaps fall into three kinds: small missing pieces around tabs, media and downloads; two organising features that Arc users rely on (folders inside folders, and rules for links from other apps); and a few larger builds (site tweaks, text in images, notifications with the tab closed) that need a decision before work starts.

The order below fixes first, then ships the small wins, then the features that change how people organise their tabs, and leaves the uncertain work for last behind a research gate.

One change to make early: idle tabs go to sleep after 30 minutes (POLICY.idleMs in apps/browser/src/lib/tabLifecycle.ts). Chat, mail and music tabs that reload whenever you come back to them read as a bug. Phase 1 adds a "keep these sites awake" list and a longer default.

Already in Bay

These are done, so nobody plans them again. Each was confirmed in the code on main.

  • Private windows
  • Close Tabs Above/Below (Left/Right with tabs on top)
  • Put Tab to Sleep from the tab menu
  • Pop-up blocker that can open the pop-up or always allow the site
  • Open at Login
  • Prompt for a page that stops responding
  • Link status bubble at the page's foot
  • Dock menu
  • Screen-share picker
  • Translate page, with the language named
  • Per-extension site access
  • 1Password's desktop app connection
  • Extension side panels
  • Import from Arc, Chrome, Safari, Firefox, Zen, Dia, Helium and more
  • Reopen closed tab (⇧⌘T)
  • Check for Updates
  • App icon picker in Settings › Appearance
  • Sidebar on either side, or tabs on top
  • Toolbar that hides while scrolling
  • Peek for links from pinned tabs
  • Split View, and Split with Current Tab
  • Picture in picture for a page's own windows
  • Calculator in the command bar
  • Per-site zoom
  • Cast
  • Task manager
  • Replace Pin with Current Page, and Back to Pinned URL
  • Custom keyboard shortcuts

Fixes

Browsers built on the same parts commonly break in these places. None is known to be broken in Bay. Each is a check: run it, and fix what fails. They make up Phase 0.

#AreaHow to check
1Shortcuts on other keyboard layoutsOn AZERTY, ⌘Z undoes and doesn't close a tab. On German, ⌘[ and ⌘] go back and forward. On Dvorak, shortcuts follow the key's letter.
2Extension popups that close themselvesBitwarden's popup goes away after Fill, as in Chrome (window.close() from a popup).
3Password managers right after launch1Password, Bitwarden and NordPass buttons work on the first click after launch, and after the app has been idle.
4Passkey prompts from extensionsBitwarden's passkey prompt opens once, closes after a pick, and GitHub's "Continue with passkey" finishes, also on a page left open a while.
5Extension pages at every launchNo welcome or changelog page opens again on relaunch. Removing an extension also removes its data.
6A helper app quittingQuitting a password manager's desktop helper while its extension is connected doesn't take Bay down.
7Sign-ins through quit, update and crashA site that keeps you signed in with a session cookie (YouTube's chosen account, for one) is still signed in after ⌘Q, an update and a Force Quit.
8Leaving a call⌘W on a Meet tab, or ⌘Q during a call, leaves the call for the others at once.
9Google's service iconsDrive, Calendar, Gmail and Maps show their own icons in the sidebar, not Google's G.
10Horizontal scroll vs. swipeScrolling a carousel or a wide table sideways doesn't go back or forward.
11Keys on a pageArrow keys, Home and End on a page (or a video that seeks with them) don't play the error sound.
12Waking a sleeping tabA tab that slept comes back scrolled to where it was.
13Icons behind a bot checkSites that check for bots first (Cloudflare's page, for one) end up with their own icon, not a letter.
14Dragging a tab outA tab dragged past the window's edge opens in a new window without reloading, including from a window that fills its screen.

Phase 0

Fix sweep

Run the 14 checks under Fixes on a release build and fix what fails, before new features land on top.

Depends on
Nothing
Setup
A release build. Bitwarden, 1Password and NordPass installed. A keyboard set to AZERTY, German and Dvorak in turn. A Google Meet call with a second participant.
  • Record each check as pass or fail, with steps for each failure.
  • Fix the failures at the narrowest layer (app, shell or engine patch), each with a regression test where the harness can reach it.
  • Add the passing checks to the release checklist so they stay passing.

Exit criteria

  • All 14 checks pass, or the failures that remain are filed with a reason they wait.
  • The release checklist lists the checks.
Phase 1

Quick wins

Small, contained items. Each one can ship alone.

Sites kept awake, and a longer idle timer S

Today
POLICY.idleMs is 30 minutes. Pinned and kept tabs are spared, and so are tabs that play audio, capture, show picture in picture or are picking a screen to share.
Build
Settings › Tabs gets "Always keep these sites awake", seeded with chat, mail and music sites (WhatsApp, Telegram, Slack, Discord, Gmail, Spotify). The tab menu gets Keep This Site Awake. The sweep in tabLifecycle.ts skips those sites unless memory is critical, and then takes them last. Raise the default idle time (see Decisions).
  • A WhatsApp Web tab left alone for two hours is still live when you switch to it.
  • Under critical memory pressure, kept-awake sites sleep only after every other tab.

Copy File and Copy Path on downloads S

Today
Download rows offer Show in Finder (DownloadsPanel.tsx, Downloads.tsx, pages/DownloadsPage.tsx).
Build
Add Copy File (the file on the pasteboard, ready to paste into Finder, Slack or Mail) and Copy Path. Add a shell call that writes a file URL to NSPasteboard if none exists.
  • Copy File, then ⌘V in Finder, copies the download. Copy Path pastes its full path.

Extensions in private windows S

Today
Settings › Extensions sets each extension's site access. It has no private-window switch.
Build
Add "Allow in Private Windows" to each extension, off by default, backed by Chrome's own incognito-enabled preference through nncore.
  • An extension that is switched on runs in a private window. Switched off, it doesn't.

Every playing tab, with Pause All S

Today
media/state.ts tracks a session for each tab. The sidebar player shows one.
Build
When more than one tab is playing or paused, the player shows "+N". It opens a list of those tabs, each with play/pause, mute and Go to Tab, and Pause All at the top.
  • With three tabs playing, Pause All pauses all three, and each row's controls act on its own tab.

Fold a space S

Today
Pinned folders can fold (PinnedFolder.collapsed). The space as a whole can't.
Build
Clicking the space's name in SpaceTitle.tsx folds its pinned tabs and folders away, or brings them back, as in Arc. Its menu moves to ••• and right-click. The folded state is stored with the space.
  • Folding hides the pinned section, survives a relaunch, and leaves today's tabs in view.

Density S

Today
Row sizes are fixed in sidebar/tokens.ts.
Build
Settings › Appearance › Density: Comfortable (Arc's 36-point rows and 16-point icons) or Compact (today's sizes). Rows, pins and the address field change together.
  • Switching density resizes rows, pins and the address field at once, with no clipped text in either size.

Exit criteria

  • All six items are shipped behind their settings, with their checks passing.
Phase 2

Organising

The two features that change how people arrange their tabs and links.

Folders inside folders L

Today
PinnedFolder in store/types.ts has no parent, so folders are one level deep. The Arc importer (packages/import/ios/Core/ArcSidebar.swift, flatTabs) flattens Arc's subfolders into one folder.
Build
Add a parent to folders, capped at five levels. Render them recursively in FolderBlock.tsx. Let drag and drop in sidebar/dnd.tsx drop into and out of a nested folder. Show "Move to Folder" as a tree. Keep subfolders in the Arc import. Migrate stored state and the sync schema, so that a device on an older version still shows the tabs, flattened.
Depends on
A decision on how older synced devices see nested folders (Decisions).
  • An Arc import with subfolders arrives with the same structure.
  • Dragging a tab or a folder between levels works, and ⌘Z undoes it.
  • Sync round-trips nested folders between two Macs. An older build still sees every tab.
  • Existing installs migrate with no change to what they show.

Rules for links from other apps M

Today
Settings › Links has one choice for links from Slack, Discord or Mail: Little Bay, or a new tab (openLinksInLittleBay). Incoming links are handled in lib/appIntegration.ts.
Build
An ordered list of rules. Each has an address pattern (a host or path with *, such as github.com/acme/*) and, optionally, the app the link came from. Each rule opens matching links in a chosen space, in Little Bay or in a new window. The first match wins, and anything unmatched follows today's choice. Rules are added, edited and reordered in Settings › Links, and synced.
  • With a rule for linear.app/* going to Work, a Linear link clicked in Slack opens in Work, whichever space is in front.
  • A link that matches no rule behaves as it does today.

Exit criteria

  • Both features are shipped, the migration has been tested on a copy of a real profile, and sync is tested across two Macs.
Phase 3

Command bar & autofill

Make the command bar answer more, without leaving it, and fill one-time codes.

Clipboard history M

Today
None.
Build
Opt-in in Settings › Privacy. The shell watches the pasteboard's change count and keeps the most recent text and links on this Mac only. It skips anything marked concealed or transient (password managers mark theirs) and anything copied in a private window. Type "clipboard" in the command bar, or use a shortcut, to list it. Return pastes the item, and an item can be deleted.
  • A password copied from 1Password never shows. Clearing history empties it, and it never syncs.

Emoji, units and currency M

Today
packages/core/src/calculator.ts does arithmetic and functions. emojiData.ts already feeds the icon picker.
Build
In suggest.ts: emoji by name ("emoji heart"), with Return to copy. Unit conversions ("5 km in mi", "350 f to c") from a local table. Currency ("100 usd in inr") from a rates source (Decisions).
  • Each kind shows as the top row with its answer, and Return copies it.

One-time codes L

Today
Autofill covers passwords, cards and addresses (site/Autofill.tsx, engine nn_autofill.cc). It doesn't cover codes.
Build
When a field asks for a code (autocomplete="one-time-code", or a field the heuristics recognise), offer the newest code from the last few minutes, and Return puts it in. There are two sources. Messages needs Full Disk Access to read chat.db, so it's asked for only when switched on. Gmail can reuse the Google connection the calendar preview already has (live/googleAuth.ts), if its scopes allow. Skip numbers from security notices, and prefer the newest code.
  • A code texted or mailed to you is offered under the code box within seconds, and only on the site that asked.

"Allow ads here" when a page breaks M

Today
uBlock Origin Lite is built in. Nothing notices when blocking breaks a page.
Build
If a page where the blocker acted is reloaded three times in twenty seconds, offer "Allow Ads Here" in the corner. It adds the site to the blocker's allow list, and Site Controls can take it back.
  • Three quick reloads offer the prompt once. Accepting reloads the page unblocked, and Site Controls shows the exception.

Exit criteria

  • The four items are shipped. Clipboard history and codes are opt-in, and both are covered in the privacy page's copy.
Phase 4

Media

Bring the floating video up to the controls people reach for.

Speed and subtitles on the floating video M

Today
Bay's PiP window (engine/chromium/src/chrome/browser/bay/pip/nn_pip_window.cc, NNCorePictureInPicture.mm) leaves out Chrome's captions control. The page script already reports playbackRate.
Build
A speed button with a short menu (0.5× to 2×) and a subtitles button listing the video's text tracks, both in the window's top row.
  • On YouTube, the speed and subtitle choices made in the floating window carry back to the page.

Live streams labelled Live S

Today
A live stream shows a countdown or a time that doesn't mean anything.
Build
When a video's duration is infinite, or its seekable range keeps moving, the floating video and the sidebar player say Live. Behind the live edge, they say how far behind ("5m behind"), and a click jumps back to live.
  • A YouTube or Twitch live stream shows Live, and "behind" after seeking back.

Exit criteria

  • Both items are shipped and checked on YouTube, Twitch and one site with its own player.
Phase 5

Bigger bets

Research gate

Each needs a short spike and a go / no-go note before it's built.

Site tweaks and Zap L

Today
Only the ad blocker's cosmetic filters change pages (NNCoreContentBlocker.mm).
Build
First, Zap: pick an element on the page and hide it for that site. Reuse the developer inspector's picker (developer/inspectorScript.ts), and store the rule as a cosmetic filter for each space. Then site tweaks: a site's own CSS (and later, perhaps, JS), edited from Site Controls, switched on and off per site, and synced.
Spike answers
Can cosmetic rules be added at runtime without rebuilding the blocker's lists? Should user JS ship at all, given the security cost?
  • A zapped element stays hidden after reloads and on other pages of the site. Site Controls lists it and can undo it.

Copy text from images M

Today
None.
Build
Start with a context-menu item, Copy Text from Image, that runs Vision text recognition in the shell on the image's pixels. Selectable text over images, and ⌘F finding words in images, come later if the first step earns it.
  • Right-clicking a screenshot of text copies its words, on this Mac, with nothing sent anywhere.

Site notifications with the tab closed Unknown

Today
Notifications work while the site's tab is open (lib/webNotifications.ts).
Spike answers
Chromium's web push relies on Google's push service, which ungoogled builds take out. Can Bay's engine receive push at all? If it can't, the choices are to run its own push relay, or to keep chosen sites' service workers alive in the background.
  • The spike ends in a written decision: build (with which approach) or drop.

Exit criteria

  • Each bet has a go / no-go note. The ones that go have been planned as their own phase.

Decisions needed

  1. The idle sleep timer. Keep 30 minutes, move to a few hours, or let it be set in Settings › Tabs. Chrome only discards tabs under memory pressure.
  2. Where link rules can send links. A space, Little Bay and a new window are proposed. Is a specific profile or window also needed?
  3. How older synced devices see nested folders. Flattened (proposed), or held back until every device updates.
  4. The currency rates source, or currency left out, keeping the command bar fully offline.
  5. The scope of site tweaks. CSS and Zap only, or JS as well.
  6. Whether to read Messages for codes, given the Full Disk Access prompt.

Assumptions in this plan

  • "Missing" comes from searching the code on main. The app wasn't run, so a feature that exists under an unexpected name may be listed by mistake. Check before starting each item.
  • Sizes are rough estimates for one person who knows the codebase.
  • The fixes are areas to check, not confirmed bugs.

Not in this plan

  • AI assistant features in the browser
  • A built-in mail client
  • An iPhone app
  • The Windows port, which has its own plan
