3. Implementation follow-ups

These are the unresolved behaviours from earlier feature work.

  • Support SVG responses in favicon fetching.
  • Handle dialog_busy and failed saves in the text-file dialog callers. Consider remembering the last save folder.
  • Fix Ctrl-Tab release before focus reaches the document, and cancellation when the user clicks inside an embedded page.
  • Check Clear animation under main-thread load and address dropped frames if needed.
  • Ensure release builds enable Crashpad and assess symbolication for useful crash stacks.
  • Port the acceptance scripts' input and window assertions. Define replacements for unsupported windowDrags checks; handle the test hooks' ignored timing and transparency options.
  • Improve tab-drag previews: composite page content, include favicons, and wait for destination content before fading. Investigate Linux preview support within each window system's constraints.
  • Add the Window menu's window list and the Extensions menu to the in-window app menu. Evaluate Alt activation and menu placement.
  • Add web-preview support for recordShortcut and audit shortcut actions that still lack an effective target.
  • Keep Little Bay accessible after the last Linux window closes, and start its put-away timer in the shared runtime. Validate global-shortcut and tray availability across desktops.
  • Add external-app icons to the open-in-app prompt where the desktop exposes them.
