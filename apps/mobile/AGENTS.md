# Bay mobile

Bay for iPhone (and later Android). Expo SDK 58 + Expo Router, HeroUI Native (Uniwind/Tailwind) for React UI, `@expo/ui/swift-ui` for native SwiftUI controls (Liquid Glass toolbars, menus, sheets). The plan lives in `docs/mobile-plan.html`.

This is a standalone project with its own `pnpm-workspace.yaml` and lockfile. The repo root's workspace excludes it because the desktop app pins react-native-macos 0.81 in a hoisted `node_modules`. Always run `pnpm` from `apps/mobile`.

## Toolchain

- `xcode-select` points at the Command Line Tools on this Mac, so export `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` for any build, `simctl` or Argent command (or run `sudo xcode-select -s /Applications/Xcode.app` once).
- It is a dev-client app (`expo-dev-client`), not Expo Go: Expo UI and our native modules need a native build.
- `ios/` and `android/` are generated by `expo prebuild` and git-ignored. Native changes go in config plugins or local Expo modules (`modules/`), never hand edits to `ios/`.

## Run it

```sh
cd apps/mobile
pnpm install
pnpm ios                    # expo run:ios: prebuild if needed, build, install on the booted simulator
pnpm start                  # Metro for the dev client (run in the background)
```

- Do not start Metro with `CI=1`: that turns off file watching, so edits never reach the app.
- If the app shows "Could not connect to the server", it was opened before Metro was up. Relaunch it with `open-url` on `exp+bay://expo-development-client/?url=http%3A%2F%2F127.0.0.1%3A8081`.
- Bundle id: `in.krishkalaria.bay.mobile`. Scheme: `bay://`.

## Drive it with Argent

Argent (`@swmansion/argent`) is set up at the repo root: `.mcp.json` registers the `argent` MCP server and its skills sit in `.agents/skills` (symlinked into `.claude/skills`). Use it to see every UI change on the simulator:

1. `list-devices` → pick the booted iPhone (boot one with `boot-device` if none).
2. `launch-app` with `in.krishkalaria.bay.mobile`, or `open-url` with the dev-client URL above.
3. Take tap targets from `debugger-component-tree` (React) or `describe` (native and SwiftUI), never from screenshot pixels.
4. `screenshot` after each change, and compare against the reference below.

The CLI does the same outside MCP: `argent run <tool> --udid <UDID> ...` (`argent tools` lists them).

## Design reference

The UI follows Lens (lens.maximos.work). Lens is App Store/TestFlight only, so it cannot be installed on a simulator. `apps/mobile/.reference/` (git-ignored) holds its press kit screenshots, the demo video (`lens-demo.mp4`) and one frame per second of it (`video-frames/`). To compare against the real app, install Lens on a cabled iPhone and drive it with Argent's physical-device skills.
