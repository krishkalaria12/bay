# Bay for iPhone (native)

The native SwiftUI rewrite of `apps/mobile` (plan: `docs/mobile-native-plan.html`). Minimum iOS 15.0; Apple silicon simulators only.

- The Xcode project is generated by Tuist from `Project.swift` and isn't checked in: run `tuist generate --no-open` in this folder after changing targets or adding files.
- Build: `xcodebuild -workspace Bay.xcworkspace -scheme Bay -destination 'generic/platform=iOS Simulator' -derivedDataPath build/DerivedData build`. The `BayCore` target runs `packages/mobile-core/scripts/build-ios.sh` first, which rebuilds the Rust core and its Swift bindings (rustup's cargo, not Homebrew's).
- Debug installs as `in.krishkalaria.bay.mobile.native`, beside the Expo app; Release uses the store ID.
- Drive the simulator with Argent (`reinstall-app` with the built `Bay.app`, then `launch-app`). Give every control an `accessibilityIdentifier` equal to the Expo app's `testID`, so the `.argent/e2e` flows keep working.
